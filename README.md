# julien-rsbrg.github.io

Personal website, built with Jekyll and served by GitHub Pages at
<https://julien-rsbrg.github.io>.

A single scrolling page with a left sidebar (name, research keywords,
position, maze navigator, contact icons). Each section is an exit of a
randomly generated maze, and a marker walks the route between them as you
scroll. Drag the marker to scroll, or click a label to jump.

## Structure

```
_config.yml              name, position, keywords, contact links
_sections/*.md           page content: one file per section / maze exit
index.html               renders the sections in `order`
_layouts/default.html    page skeleton: sidebar + content
_includes/
  head.html              <head>: meta, fonts, CSS, JS
  sidebar.html           left panel: intro, maze, contact icons
  navigator.html         maze markup
  social-links.html      LinkedIn / GitHub / email icons (inline SVG)
assets/css/style.css     design tokens, layout, navigator styles
assets/js/maze.js        maze generation + route geometry (pure, no DOM)
assets/js/main.js        navigator: rendering, scroll sync, dragging
Gemfile                  github-pages gem, for local builds
```

## Editing content

- Name, position, keywords and contact links live in `_config.yml`
  (remove a `social` entry to hide its icon).
- Each file in `_sections/` is one section, written in Markdown:

  ```markdown
  ---
  title: Current research   # heading and maze label
  order: 2                  # position on the page
  label: Research           # optional: shorter maze label
  ---

  Your text here.
  ```

  The file name is the anchor (`research.md` → `#research`).
  Add, remove or reorder files freely; the maze adapts (at least two sections).
- Section numbers (01, 02, …) are generated by CSS.
- Colours and fonts are CSS variables at the top of `assets/css/style.css`.

## Local preview

```bash
bundle install                 # first time only
bundle exec jekyll serve       # http://localhost:4000, rebuilds on save
```

Changes to `_config.yml` need a server restart.

## Deployment

Push to `main`. In the repository settings → **Pages**, set the source to
*Deploy from a branch*, branch `main`, folder `/ (root)`. GitHub builds the
Jekyll site automatically.
